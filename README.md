# 🎬 YouTube Sentiment Analysis using NLP

## 📌 Project Overview

This project performs **Sentiment Analysis** on YouTube comments using **Natural Language Processing (NLP)** techniques. It classifies user comments into positive, negative, or neutral sentiments, helping analyze audience opinions and engagement.

This repository is based on an existing open-source project and has been cloned for learning, experimentation, and further enhancement.

---

## 🎯 Objectives

- Collect and analyze YouTube comments.
- Perform text preprocessing.
- Apply sentiment analysis techniques.
- Classify comments into Positive, Negative, and Neutral sentiments.
- Visualize sentiment distribution.

2. Navigate to the project folder

```bash

```

3. Install the required libraries

```bash

```

4. Open the notebook

```bash

```

5. Run all notebook cells.
